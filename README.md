# 🏛 Матрикс

**Матрикс** — это сервис интеллектуального мониторинга законодательных инициатив и регуляторных изменений. 
Система переводит сложный юридический язык (законы, правки, нормативные акты) в четкие бизнес-задачи, экономя часы работы юристов и комплаенс-офицеров.

## 🎯 Ключевые возможности
* **«Золотой стандарт» данных:** Работа с эталонно размеченными базами законов (без галлюцинаций ИИ).
* **Умная фильтрация:** Поиск изменений по отраслям (например, `AML/ПОД/ФТ`) и затронутым субъектам (`Банки`, `Страховщики`).
* **Дельта-анализ (Бизнес-суть):** Мгновенная расшифровка того, как конкретная правка повлияет на бизнес.
* *(В разработке)* **AI-модуль (RAG):** Гибридный поиск и общение с базой законов через локальные/облачные LLM.

## 🏗 Архитектура проекта
Проект построен по принципам модульной архитектуры, где интерфейс, данные и ИИ независимы друг от друга.

```text
government-radar/
├── data/                  # Data Layer: Эталонные датасеты (CSV/JSON) и справочники
├── ai_layer/              # AI Layer: Роутер провайдеров (Ollama, OpenRouter) и промпты
├── app.py                 # UI Layer: Главный веб-интерфейс на Streamlit
└── requirements.txt       # Зависимости проекта
